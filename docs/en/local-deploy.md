# Local deploy

Русский: [../ru/local-deploy.md](../ru/local-deploy.md)

## Your goal: log into the editor UI

ShiftedBlog is a **blog management tool**. After setup you should land here:

**http://localhost:5173/login** → sign in → **http://localhost:5173/posts**

That is the main workspace: write posts, manage series, publish to channels.

> **Local install does not create a public website.** It runs the system's management interface in your browser on this machine (`localhost`) — not a site visitors can open on the internet. You still get the full editor workflow, including **multichannel dispatch**: publish posts to configured channels (site backend, Telegram, …) from local once credentials are set up in admin.

The public blog preview at `http://localhost:8888/` and Django admin are secondary for local try-out.

## Prerequisites

Install these before you start:

| Tool | Why | Download |
|------|-----|----------|
| [Git](https://git-scm.com/downloads) | Clone the repository | https://git-scm.com/downloads |
| [Docker Engine](https://docs.docker.com/engine/install/) + [Compose plugin](https://docs.docker.com/compose/install/) | Runs backend and editor UI | https://docs.docker.com/get-docker/ |

Check:

```bash
git --version
docker compose version
```

Node.js is **not** required for normal use — the editor UI runs inside Docker. Install [Node.js LTS](https://nodejs.org/) only if you develop the frontend outside Docker.

Check automatically:

```bash
./scripts/check-prerequisites.sh local
```

Check ports manually (local stack uses **8888** — backend, **5173** — editor UI):

```bash
ss -tlnp | grep -E ':8888|:5173' || echo "ports 8888 and 5173 are free"
```

On macOS without `ss`:

```bash
lsof -nP -iTCP:8888 -sTCP:LISTEN
lsof -nP -iTCP:5173 -sTCP:LISTEN
```

If **5173** is in use, stop a host `npm run dev` or run `./scripts/stop-local.sh` if ShiftedBlog was started before.

On Ubuntu/Debian or macOS (Homebrew), optional install:

```bash
./scripts/install-prerequisites.sh
```

Windows: install [Docker Desktop](https://docs.docker.com/get-docker/) manually; use Git Bash for scripts and `start-shiftedblog.bat`.

## One-time setup

```bash
git clone https://github.com/askopintsev/shiftedblog.git
cd shiftedblog
./scripts/setup.sh
```

Choose **`1) local`**. The wizard creates `.env`, generates secrets, and can start Docker. The first build may take several minutes.

Create a login if the wizard did not:

```bash
docker compose exec web python manage.py createsuperuser
```

Use your **email** as the username.

## Daily start (one click)

After setup, start everything and open the editor login page:

```bash
./scripts/start-local.sh
```

Or double-click a launcher in the project folder:

| File | Platform |
|------|----------|
| `Start ShiftedBlog.command` | macOS |
| `start-shiftedblog.desktop` | Linux (generated by setup; copy to Desktop if you like) |
| `start-shiftedblog.bat` | Windows (needs Git Bash; Docker Desktop must be running) |

The script starts Docker (backend + editor UI), waits until services are ready, and opens **http://localhost:5173/login** in your browser.

Stop when done:

```bash
./scripts/stop-local.sh
```

## Troubleshooting

**Database password errors after re-running setup**

```bash
docker compose down -v
./scripts/setup.sh   # choose local again
```

**Start script times out**

Check `docker compose ps` — db should be **healthy**, web and editor-ui **running**. View logs: `docker compose logs web editor-ui`.

**Editor login fails**

- Run `./scripts/start-local.sh` again and wait for “Editor UI is ready”
- Use the same email/password as `createsuperuser`

**Linux desktop shortcut**

If `start-shiftedblog.desktop` is missing, generate it:

```bash
sed "s|@PROJECT_ROOT@|$(pwd)|g" start-shiftedblog.desktop.in > start-shiftedblog.desktop
```

## Advanced: virtualenv (no Docker)

You need PostgreSQL and Redis on the host, plus Node.js for the editor UI:

```bash
cp env.example .env
# edit DB_HOST=localhost, REDIS_URL=redis://localhost:6379/1, DEBUG=True, …
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
cd editor-ui && npm install && npm run dev
```
